# 九九ゲームひろば

小学2年生を主な対象にした、無料の九九・掛け算学習ゲームです。インストールやログインは不要で、スマートフォン、タブレット、パソコンのブラウザから遊べます。

**公開サイト:** [九九ゲームひろばを開く](https://moharamo.github.io/kakezan-learning-games/)

## このサイトについて

九九を順番に唱える段階から、問題を見て素早く答える段階まで、4種類のミニゲームで練習できます。単に問題を繰り返すだけでなく、リズム、惑星、列車、忍者という異なる遊び方を用意しています。

- キーボードを使わず、タッチ操作だけでも遊べます
- 画面幅320px以上のレスポンシブ表示に対応しています
- ゲームとレベルは最初からすべて選べます
- 学習記録はブラウザ内だけに保存され、サーバーへ送信されません
- 問題の読み上げには、VOICEVOXの「四国めたん（ノーマル）」による音声を使用しています

## 収録ゲーム

### 🎤🎵 九九リズム

1の段から9の段まで、九九の読み方と並びをリズムに合わせて覚えます。式と「いんいちが」のような唱え方を見聞きし、声または数字パッドで答えます。

### 🚀🪐 九九ロケット

選んだ段の九九を順不同で出題します。正しい答えが書かれた惑星へロケットを飛ばし、順番に頼らず答えを思い出す練習をします。

### 🚂🚉 九九れっしゃ

複数の段を混ぜて出題します。正しい数字へ続く線路を選び、異なる段へ切り替えながら九九を思い出す練習をします。

### 🥷📜 九九にんじゃ

九九81問からランダムに出題される、選択肢なしの仕上げゲームです。レベルが上がるほど制限時間が短くなり、数字パッドで素早く答えます。

## 学習設計

ゲームは、おおむね次の順番で取り組めるよう設計しています。

1. 九九の読み方と順番を覚える
2. 選んだ段を順不同で思い出す
3. 複数の段を混ぜて思い出す
4. 九九81問へ選択肢なしで素早く答える

想起練習、間隔を空けた練習、混合練習などの知見を参考にしています。設計上の根拠と注意点は [`docs/research.md`](docs/research.md) と [`docs/learning-spec.md`](docs/learning-spec.md) にまとめています。

## 対象・利用場面

- 小学校2年生の九九学習
- 家庭学習や授業後の復習
- 九九を覚え始めた子どもの反復練習
- 九九を覚えた後のスピード練習

子ども一人でも操作できるようにしていますが、最初は保護者や先生と一緒に遊び方を確認してください。

## 開発環境

Vanilla HTML、CSS、JavaScriptで作られており、外部フレームワークは使用していません。

```powershell
# 開発サーバーを起動
.\scripts\dev.cmd

# 自動テストを実行
.\scripts\test.cmd
```

Node.jsがPATHに設定されている環境では、次のコマンドも利用できます。

```text
npm run dev
npm test
```

## プライバシー

ログイン、広告、個人情報の送信はありません。ゲームの設定や記録にはブラウザのローカルストレージを使用します。アクセス解析には GA4 を使用しており、IP 匿名化・広告向け識別の無効化を行っています。ユーザー識別のための user_id や、子どもの名前・顔・声・位置情報は送信しません。詳しい方針は [`docs/child-safety-privacy.md`](./docs/child-safety-privacy.md) を参照してください。

### GA4 の設定方法

`index.html` の `window.__GA4_MEASUREMENT_ID__` に `G-XXXXXXXXXX` 形式の測定IDを設定します。空、または形式が不正な場合はイベント送信を行いません。

### GA4 のレポート設計

イベントの定義と、GA4 で見るべき指標は [`docs/ga4-reporting.md`](./docs/ga4-reporting.md) にまとめています。
